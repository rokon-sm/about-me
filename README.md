# About Me

A simple personal profile website built with HTML, CSS, and JavaScript. No frameworks, dependencies, or build step.

## Features

- Animated profile card with avatar and bio
- Background image or video
- Music player
- Animated stats
- Customizable link buttons
- Fullscreen mode

## Setup

1. Clone the repo.
2. Add your assets to `assets/`.
3. Edit `config.js` with your details.
4. Open `index.html` in your browser.

## Files
```
index.html   # Page structure
style.css    # Styling and animations
script.js    # Functionality
config.js    # Personalization
assets/      # Images, favicon, and music
```

## Configuration

Everything is configured in `config.js`, including:

- Name, bio, and avatar
- Background and blur
- Music and volume
- Stats and links
- Page title and favicon

Link buttons support opening URLs or copying text. Remove an entry from `links` to hide a button.

## Deployment

Deploy to any static hosting provider, such as [Vercel](https://vercel.com/) or [GitHub Pages](https://pages.github.com/).
